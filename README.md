# C Low-Level Fundamentals (Woong Jeon)

이 저장소는 『C 언어 펀더멘탈 - 견고한 프로그램을 위한 기본 원리』(전웅, 한빛미디어)에서 소개된 예제 코드를 직접 작성하고 정리한 학습용 저장소이다.

## 🎯 목적

- C 언어의 기초를 넘어 로우레벨 동작 이해
- 포인터, 메모리, 타입 시스템 핵심 개념 정리
- 시스템 및 그래픽스 프로그래밍을 위한 기반 구축
